# IoT Smart Juice Vending Machine

An automated, cashier-free juice vending machine integrated with instant digital payment authentication and motorized dispensing.

##  Hardware & Components
- Controller: ESP32 
- Inputs: Dynamic QR Display
- Actuators: 12V DC Peristaltic pumps 

##  Tech Stack
- **Firmware:** Embedded C 
- **Protocols:** Wi-Fi, SPI

## Key Features
- Real-time scan-and-pay payment verification before dispensing liquid.
- Precise volume calibration via motor-actuation timing.
